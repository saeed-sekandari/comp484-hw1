Perhaps the most important aspect of HTML is the ability to link from one document to another. This is the basic concept underlying the web. Without this functionality, the World Wide Web would not exist.

Link Syntax

Creating links is relatively straightforward. To create a link, you use the anchor element (<a>) to wrap the content you want to convert into a link. Attributes inside the anchor tag tell the browser where the page is linking to.

Take the following link example:

<a href="syntax.html" title="Learn more about syntax">HTML syntax</a>

The text “HTML syntax” would appear as a clickable link. The href attribute tells the browser where to go when the link is clicked. The optional title attribute provides extra information about the link.

Link Types

There are three basic types of links: absolute, site-root relative, and document relative.

Absolute Links

Absolute links contain the complete URL, including the protocol. They are usually used for external websites. 

<a href="https://www.google.com" title="Visit Google">Google</a>

Document Relative Links

Document relative links are commonly used to navigate between pages inside the same website. 

<a href="contact.html" title="Our contact page">Contact us</a>

This example assumes that contact.html and the current page are in the same folder.

If the contact page is inside a folder named resources, use: 

<a href="resources/contact.html" title="Our contact page">Contact us</a>

To move up one folder, use ../: 

<a href="../contact.html" title="Our contact page">Contact us</a>

Site-Root Relative Links

Site-root relative links start from the website’s root folder. They begin with a forward slash. 

<a href="/contact.html" title="Our contact page">Contact us</a>

If the contact page is inside a resources folder, use: 

<a href="/resources/contact.html" title="Our contact page">Contact us</a>

Fragment Identifiers

A fragment identifier links to a specific location on the same page. The destination element needs an id attribute. 

<h2 id="camp">Camping</h2>

You can link to that heading using the hash symbol:

<a href="#camp">Learn more about camping</a>

You can also link to a specific section on another page: 

<a href="faq.html#camp">Read our FAQ on camping.</a>
