Once you master the basics of authoring HTML, you will need to focus on what your next steps will be. If you are an aspiring web designer, you will need to learn more about HTML, CSS, and JavaScript. If you maintain a website through a CMS, you will need to learn how the CMS works and how to edit and maintain content efficiently. This page provides basic advice about learning web design and additional resources that can help you.

Learning Web Design

“Web design” is a broad term. People who are new to web design can feel overwhelmed by everything there is to learn. That is understandable, but remember that web design is like any other discipline. With dedication and focus, you can progress quickly.

Learn how the web works

I am always amazed at how many web designers focus on learning only what they need to know and ignore how the web actually works. Without understanding web servers, protocols, browsers, and other related technologies, you will not understand the reasons behind the decisions you make.

Determine an area of focus, and start there

There are many areas of web design in which you could specialize. Learn about different areas to determine which ones interest you. Then spend time learning about your specific area of focus. Once you become proficient, begin learning about other areas as well.

Never stop learning

The web is constantly evolving. New techniques and approaches can appear every year. Being a good web designer means accepting the changing nature of the web and continuing to learn.

Break things!

There is no better teacher than experience. Build and experiment constantly. Ask yourself, “What would happen if I tried this?” and then build it. You may fail sometimes, but trying new things and fixing problems will help you improve. Always challenge yourself.

HTML Specifications

Although HTML specifications can be difficult to read at first, they are excellent resources for learning HTML and keeping up with current standards.

W3C Markup Validation Service

This service is useful for testing your code and making sure you are writing valid HTML syntax.

Mozilla Developer Network

Mozilla Developer Network is one of the best online resources for web designers and developers. It contains articles, tutorials, and references.

HTML5 Rocks

Once you understand the basics, check out websites such as HTML5 Rocks. This site features articles, tutorials, and other resources that can help you keep up with the evolving web.
